# File-Upload-Web-App
File Upload Web App A simple and modern full-stack web app that allows users to upload files (PDFs and images) into categorized folders with real-time feedback and preview. Built using React (frontend) and Flask (backend).
🚀 Features
✅ Upload .pdf, .jpg, and .jpeg files

✅ Choose a category (HR, IT, Sales, etc.)

✅ Files are saved in backend folders named by category

✅ Instant preview of uploaded file (PDF viewer or image)

✅ Success and error messages for user feedback

✅ Backend logging of all uploads (upload_log.txt)

Frontend

React.js

Axios

Plain CSS

Backend

Python
